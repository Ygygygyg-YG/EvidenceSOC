# Task13 E 空计划修补实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 保留合法null，并提供可解释、可持久化、无虚假计时信用的终态。

**Architecture:** 产品可选原因贯穿状态和审计；worker复用verification区分无候选；host保存blocked并拒绝依赖派发。旧冻结版本与实际结果不变，新代码只有验证后才能成为新执行候选。

**Tech Stack:** Python/Pydantic/LangGraph/pytest，现有PostgreSQL/OpenSearch隔离机制。

## Global Constraints

- 本计划只读真实结果、不得读.env、调用模型、登记真实epoch或槽、写真实预算或取得虚假批准。
- 旧合法`{"response_plan":null}`必须保持valid、不得因缺理由重试或调用fallback。
- no_plan、blocked不增加完整计时，导出仍须三次真实完整六分支；TTL仍1800秒、余量规则不变。
- 导入诊断、来源、证据、知识、封印、原始请求和响应不可改写。
- unknown、真实异常、清理失败和模型身份漂移不得掩盖为no_plan。
- 使用独立task13-null-plan分支；冻结4953及全部旧登记字节不变。
