# EvidenceSOC 安全模型

本文件描述本地演示系统的信任边界和验收要求。安全测试证明的是应用约束及恢复行为；受控模型响应测试不代表真实供应商模型能够抵御所有提示注入。验收状态以同版本原始测试、覆盖率、性能和浏览器报告为准，未执行的检查不计通过。

## 输入与模型边界

日志正文、主机名、账号、URL、路径、工具返回和检索资料均为待核对数据。模型只提出结构化判断和工具建议，不能修改工具白名单、调查范围、预算、审批人或执行器配置。URL和路径作为证据文本，不形成任意网络抓取、文件读取或进程执行权限。接入和知识准备命令的文件访问属于操作人员明确调用的控制侧能力，不暴露给调查模型。

模型输入经过字段投影和大小限制；结构化结果还要通过字段、类型、引用、目标和状态校验。结构正确不等于事实正确，无法确认的结论保留不确定状态。超时、无效输出、空结果、服务异常及规则回退均保留实际原因，不产生虚假的成功验证。

## 工具与数据范围

调查只公开 `search_security_events`、`get_alert_context` 和 `lookup_attack_technique` 三个只读工具。工具名、参数和查询字段由服务端验证；服务地址来自受控配置。运行身份和案件锚点由服务端私有上下文绑定，不由模型传入的参数替代。

调查查询受案件、数据集/场景、证据、时间范围及返回数量约束。跨案件访问、扩展范围、未知参数和未知工具必须在受约束执行路径中被拒绝。正常可搜索的可疑文本不需要一概拒绝，但不能被解释为程序、查询配置或授权。

每轮最多3次、调查累计最多6次取证逻辑调用；物理尝试最多3次。失败和空结果消耗逻辑预算，重复请求按持久台账复用结果。验证查询独立标明用途。检查点恢复不得重新授予已消耗预算，不得把未知调用当作未发生自动重放。

## 审批与模拟处置

计划、调查、证据快照、版本和有效期共同约束审批。缺少真实审批、版本不匹配、证据变化、过期、重复决定或跨调查决定不能触发新的模拟处置。拒绝、转人工、失败及不可验证均是有效且必须保存的状态。

执行器仅接受应用定义的模拟动作；模型文本不能启动真实主机命令、账号操作或网络隔离。并发决定、浏览器重连及后端重启不得重复模拟已经执行的计划。事实复核和引用判断不构成处置计划批准。

## 会话、秘密与隔离

当前产品面向本机演示，使用受控本地 Origin 和演示会话。它不提供企业多租户身份、权限管理或互联网生产部署的完整认证体系；案件归属检查不能替代这些能力。

密钥和服务凭据只进入需要它们的受控进程，避免写入日志、请求参数、截图、测试报告或版本库。日志和错误输出需要脱敏。正式模型worker仅获得固定源码、必要依赖、受限配置和单案输入；评分答案、Git历史、其他案例及完整控制侧目录不能挂入worker。源码、数据、知识、依赖和镜像的实际身份须与冻结及隔离回执一致。

## 故障恢复与验收

REST/SSE以持久事件游标和检查点恢复。使用 `Last-Event-ID`、刷新、断线、重启以及取证预占后、结果确认前、节点返回前的中断测试，核验顺序、预算、幂等和实际结果。依赖故障必须导致明确失败、降级或转人工，并有可审计记录。

故障试验只操作本轮自有验收资源，不停止共享实验服务。模型超时、HTTP错误和错误结构可通过本地受控接口验证应用处理，不记作真实供应商实验或F8成绩。

Task14要求关键后端包分别达到80%覆盖率，必要真实服务测试零跳过；首个真实TCP SSE小于2秒，告警列表和案件详情各100样本的P95小于500毫秒；完整生产浏览器E2E连续三次通过且零重试、无跳过或flaky，资源清理成功。安全、故障、性能及覆盖率原始证据需绑定同一受测版本。

## 本轮实验边界

本轮先完成176行独立回归、16槽新人工复核和Task14。Task13真实六分支计时及F8延期，Task15不纳入。工程测试、合成观测、真实模型效果和模拟处置效果分开报告；缺失实验保留延期或N/A。若安全修复改变模型输入、取证、字段投影、审批或证据边界，应重新冻结并另存受影响实验复验结果，不能把旧版本分数直接归给修复后的版本。
